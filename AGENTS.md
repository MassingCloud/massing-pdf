# Agent instructions

The working notes for this repository live in **[CLAUDE.md](CLAUDE.md)** — architecture, the
non-negotiables, the commands, and a list of traps that have each cost real debugging time.

This file exists so agents following the `AGENTS.md` convention find them. It deliberately holds no
content of its own: the two were byte-identical copies, which meant the next edit to either would
silently leave the other stale, and a confidently wrong trap list is worse than none.
