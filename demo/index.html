Massing PDF

A construction drawing review desk: markup, calibrated takeoff, issue pins, revision compare, and XFDF / BCF interchange. Everything runs in this tab — no upload, no server, and your markups are stored locally in this browser.

  • Pick a drawing scale (or draw a calibration line), then measure.
  • c revision cloud · p issue pin · d distance · e area · n count
  • v select · Esc cancel · Ctrl+Z undo · Ctrl+scroll to zoom
  • Polygon tools: click each vertex, then double-click or Enter to finish.
